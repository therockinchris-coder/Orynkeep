# Orynkeep v0.1

- Self-hosted backend storage using local disk.
- PostgreSQL metadata database.
- Single administrator account initially.
- Basic file operations and folders.
- Simple rich-text office app: headings, bold, italic, lists, autosave.
- Simple photo area: upload, thumbnails, gallery, full-image viewing.
- Docker Compose, installation documentation, and tested backup/restore.

Deferred: collaboration, spreadsheets, presentations, public links, mobile
photo backup, face grouping, and semantic search.

Current milestone: first-run administrator setup (login follows next). Name availability and project license
selection remain outstanding decisions.
